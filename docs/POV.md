# POV（Point of View）

## 1. テーマ

履修登録の簡略化

## 2. 対象ユーザー

履修登録を行う大学生

## 3. ユーザーが抱える課題

- 履修登録の手順が多く、操作に時間がかかる。
- 履修登録の途中経過を保存し、後から再開することが難しい。
- どの科目を履修すればよいか判断しにくい。
- 再履修科目の調整に手間がかかる。
- 履修登録サイトの動作が重く、操作しにくい。
- 履修科目を決めるための参考情報が不足している。

## 4. ユーザーニーズ

履修状況を確認しながら、少ない手順で履修計画を作成・保存し、必要に応じて修正できるようにしたい。

## 5. 統合したPOV

履修登録を行う大学生は、履修状況を把握しながら、簡単に履修計画を作成・保存・修正できる仕組みを必要としている。

なぜなら、既存の履修登録では操作に手間がかかり、履修する科目の判断や再履修の調整が難しいためである。

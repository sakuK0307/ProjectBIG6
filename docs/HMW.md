# HMW（How Might We）

## 1. テーマ

履修登録の簡略化

## 2. HMWの目的

POVで明らかになった課題を「どうすれば〇〇できるだろうか？」という問いに変換し、解決策の可能性を広げる。

## 3. HMWの検討内容

### 3.1 履修登録サイトの操作性

- どうすればサイトを上手く使えるだろうか？
- どうすればサイトを使いやすくできるだろうか？
- どうすれば使いにくいサイトを快適なサイトにできるだろうか？
- どうすれば履修登録自体を簡単にできるだろうか？

### 3.2 履修登録の負担軽減

- どうすれば履修登録の難しさをなくせるだろうか？
- どうすれば迷わずに登録できるだろうか？
- どうすれば手順の多さを楽しく感じられるようにできるだろうか？
- どうすれば履修登録を楽しいものにできるだろうか？

### 3.3 履修登録の情報・データ活用

- どうすれば一度に情報を検索できるサイトにできるだろうか？
- どうすれば情報工学の知識を履修登録のプロセスに活かせるだろうか？

### 3.4 履修登録方法の見直し

- どうすれば履修登録をもっと簡単にできるだろうか？
- どうすれば履修登録を楽しくできるだろうか？
- どうすれば履修登録という行為を減らせるだろうか？

## 4. HMWから考えられる設計の方向性

以下はHMWを踏まえた整理案であり、チームで決定した仕様ではない。

| HMWの観点 | 設計の方向性 |
|---|---|
| サイトを使いやすくする | 直感的なUI、操作手順の削減 |
| 迷わず登録できるようにする | 操作案内、必要情報の可視化 |
| 履修登録を簡単にする | 下書き保存、再編集 |
| 情報を探しやすくする | 科目検索、絞り込み |
| 履修登録の負担を減らす | 履修状況の確認、入力の効率化 |

## 5. まとめ

HMWでは、履修登録を単に効率化するだけでなく、操作性の改善、手順の削減、情報の探しやすさ、心理的な負担の軽減など、複数の視点から解決の可能性を検討した。

今後は、これらの問いをもとに具体的な機能を検討し、実現可能性や優先順位を考慮しながら設計を進める。
